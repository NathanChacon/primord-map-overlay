# Notas de versão

## 1.1.0

### Novidades

- A barra de ferramentas pode ser ocultada pelo botão de olho riscado à direita.
- Um botão com o ícone de olho aparece no canto superior direito, fora do círculo do mapa, para mostrar a barra novamente.
- F8 minimiza o overlay para a barra de tarefas; pressionar F8 outra vez restaura a janela.

### Organização interna

- O código foi separado em módulos para a página do overlay, estilos, atalhos, regras de navegação e listeners IPC.

### Instalação

- Baixe `PrimordMapSetup.exe` nos arquivos desta Release e execute o instalador.
